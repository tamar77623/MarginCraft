# # 📈 MarginCraft Calculator

**MarginCraft Calculator** is a clean, responsive, and high-utility micro-web application designed for retail business owners, merchants, and service providers to instantly calculate gross profit, profit margins, and markups.

It helps local businesses optimize their pricing strategy, evaluate product profitability at a glance, and avoid financial loss by featuring automated threshold alerts.

---

## ✨ Key Features

* **Instant Financial Breakdown:** Computes net profit, profit margin percentage, and markup percentage in real time.
* **Smart Threshold Alerts:** Automatically evaluates profitability to flag financial loss, low margins (<15%), or healthy profit margins.
* **Minimalist & Professional UI:** Styled with **Tailwind CSS** for an ultra-clean, modern layout that looks great on all screens.
* **Zero Dependencies:** Pure Vanilla JavaScript (ES6+) execution ensures instant loading speeds and lightweight client-side performance.

---

## 🧮 Mathematical Logic & Formulas

The core calculation is based on standard business retail formulas:

1. **Gross Profit ($GP$):**
   $$GP = \text{Selling Price} - \text{Cost Price}$$

2. **Profit Margin Percentage ($Margin$):**
   $$Margin = \left( \frac{GP}{\text{Selling Price}} \right) \times 100$$

3. **Markup Percentage ($Markup$):**
   $$Markup = \left( \frac{GP}{\text{Cost Price}} \right) \times 100$$
